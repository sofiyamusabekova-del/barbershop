## 1. Общие сведения и стек

- **Архитектура репозитория:** Monorepo на базе **npm workspaces** (`apps/*`, `packages/*`).
  - `apps/web`: Next.js 15 (App Router), React 19, TypeScript.
  - Планируются по ТЗ (`spec-final.md`): `apps/api` (Fastify + Prisma + Zod), `apps/miniapp` (Telegram Mini App Vite + React), `packages/shared`, `packages/ui`.
- **База данных и бэкенд (будущие этапы):** Supabase PostgreSQL, Prisma ORM, Fastify REST API.
- **Текущее состояние:** 
  - **Этап 1 (Сайт/Лендинг):** полностью выполнен и закрыт.
  - **Этап 2 (Интерфейс записи /book):** полностью выполнен и закрыт.
  - **Этап 3 (База данных):** схема Prisma, PostgreSQL Supabase, сиды наполнены.
  - **Этап 4 (Backend API Fastify + Zod + Prisma):** полностью реализован и запущен.
  - **Этап 5 (Настоящая система бронирования):** полностью реализован (алгоритм availability со слотами, защита от двойной записи через GiST exclusion в PostgreSQL, создание бронирования POST /bookings, страница управления и отмены /booking/[token], unit-тесты).
  - Следующий шаг в работе: **Этап 6 (Telegram Mini App на React + Vite)**.

## 2. Ключевые решения по дизайну и бренду (Арт-дирекшн)

По указанию пользователя применен скилл **frontend-design** / **GOATED-UI-SKILL**:

### Design Read:
- **Direction:** Modern Brutalist Luxury & Editorial Art Direction с аутентичным ташкентским городским характером.
- **Бренд:** **REMESLO** (Ташкент, Мирабадский район, ул. Тараса Шевченко, 28, координаты `41°18′05″N 69°16′42″E`).
- **Цветовая палитра (Anti-Slop):**
  - Никакого «дешевого золота», неона, размытых AI-градиентов и летающих glassmorphism-карточек.
  - Фон: глубокий базальтовый уголь (`#0f1013`, `#15171c`, `#1b1e25`).
  - Текст: тёплый оттенок льна / off-white (`#f4f3ef`).
  - Акцент: **тёмный узбекский гранат / обожженный кирпич** (`#a63232`).
  - Материалы: фактура архитектурного бетона, стальные волосяные разделители (`rgba(255, 255, 255, 0.08)`).
- **Типографика:** 
  - `Syne` (монументальный акцидентный display-шрифт для заголовков).
  - `Plus Jakarta Sans` (чистый гротеск для чтения и интерфейса).
  - `JetBrains Mono` (только для технических меток: время, координаты, номера услуг `01`, `02`).
- **Signature Moment:** Hero scroll-expansion (кадр работы мастера масштабируется при скролле, перестраивая композицию).
- **Валюта и цены:** узбекские сумы (`UZS` / `сум`), точный хронометраж.

## 3. Что уже реализовано в `apps/web`

1. **Компоненты лендинга (`apps/web/src/components/`):**
   - `Header`: минималистичный монохромный бар, при скролле становится компактным с матовой подложкой, скрывает/открывает мобильный drawer.
   - `Hero`: мощный заголовок «ТОЧНАЯ ФОРМА. ЧИСТОЕ РЕМЕСЛО.», координаты Ташкента, интерактивный cinematic frame.
   - `Services`: интерактивный нумерованный реестр услуг (`01` — Мужская стрижка, `02` — Стрижка + борода...) с ценами в сумах и sticky live-preview фото.
   - `Barbers`: асимметричная портретная галерея шеф-барбера (Джасур Рахимов) и старших мастеров студии.
   - `Works`: фотоархив реальных текстурных стрижек (`Textured Crop`, `Taper Fade` и др.) с авторством.
   - `Philosophy`: манифест студии без маркетинговой воды («Мы не делаем "модно". Мы делаем так, чтобы тебе подходило»).
   - `Location`: блок Мирабадского района, ориентиры, время работы, прямая ссылка на построение маршрута в Яндекс.Картах и Telegram.
   - `BookingCta`: финальный блок призыва к действию «ГОТОВ? САДИСЬ В КРЕСЛО.» с быстрым вызовом записи, Telegram и звонка.
   - `Footer`: лаконичный подвал со всеми реквизитами.
2. **Данные:**
   - `src/data/brandData.ts` — типизированные структуры для услуг, барберов, архивных работ и контактных данных.
3. **Сборка и валидация:**
   - `npm run build --workspace=apps/web` проверен, компилируется с кодом 0 (без ошибок типизации и линтинга).
   - Dev-сервер работает стабильно, кэш `.next` очищен, стили отдаются корректно по HTTP.

### Важные технические правила:
1. **Не ломай дизайн-систему:** Используй токены из `globals.css` (фон `--bg-base`, гранатовый акцент `--accent-ruby`, шрифты `--font-display`, `--font-body`, `--font-mono`). Никаких золотых градиентов или кислотных цветов.
2. **Команды запуска:** На этой Windows-машине запуск команд выполняется через `cmd.exe /c ...` (из-за PowerShell ExecutionPolicy).
3. **Локальный сервер:** Для проверки запущен `npm run dev:web` на порту 3000.
